# Zwroty Amazon Allegro

Prywatna aplikacja do obsługi sprzedaży w Allegro.

Aplikacja służy do identyfikacji produktów na podstawie kodów EAN/GTIN oraz przygotowywania i wystawiania ofert sprzedaży za pomocą Allegro REST API.

Aktualna wersja: 0.1.0

Aplikacja jest rozwijana na potrzeby własnego konta sprzedawcy.
